# Frontend responsive
1. Identifier la section dans `index.html` et le module `style/_<section>.scss` correspondant.
2. Lire `style/_variables.scss`, `style/_breakpoint.scss`, les styles du composant et les JS liés.
3. Modifier le minimum, sans framework ni nouvelle dépendance.
4. Préserver les points de rupture 767/768px et 1024px pour la navigation.
5. Vérifier à 390px, 768px, 1024px, 1440px ; contrôler menu fermé/ouvert si pertinent.
6. Vérifier navigation clavier, `aria-*`, titres, images et contraste.
7. Indiquer le diff, la compilation Sass si exécutée, et les validations non effectuées.
